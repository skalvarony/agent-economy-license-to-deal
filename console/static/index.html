Scenario crib

  1. Normal purchase: ask the agent for a spa day; approve; see the order here, door "Agent, signature verified", and the payment in Stripe.
  2. Surprise fee: set the fee while a proposal waits; approve; the agent stops and asks again. Remove the fee after.
  3. Fake bot: scripts/prove_door.py or a curl without a signature: 401.
  4. Merchant cancels: open the order, Cancel, then Refund; the code goes void, the coins come back, Stripe shows the refund.
  5. "I never bought this": open the order; the agent's side shows the approval, the conversation and the findings.
